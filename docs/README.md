# Nexilis

Nexilis is client and server API for multiplayer game development with TCP/UDP.

## Project structure

```
nexilis/          - Core C++ library (client + server)
bindings/         - Language bindings (C#)
tests/            - Test suites
examples/         - Examples of library usage
docs/             - Documentation
```

See `docs/server_message.md` for the wire format.
